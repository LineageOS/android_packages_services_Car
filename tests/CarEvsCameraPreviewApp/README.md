# CarEvsCameraPreviewApp (Deprecated)

> **DEPRECATED**: This EVS-based sample application is deprecated and scheduled for removal.
> **Migration**: Transition to the Camera2-based [SampleRearViewService](../SampleRearViewService/) for the updated reference implementation.

## Summary

`CarEvsCameraPreviewApp` is a legacy reference application demonstrating rearview camera functionality using the Extended View System (EVS) API.

## Why it is Deprecated

The EVS API is scheduled for deprecation in the **26Q2 release**. Modern automotive implementations should use the **Camera2 API**.

## Migration Path

Developers currently using `CarEvsCameraPreviewApp` can refer to **SampleRearViewService** as a new Camera2-based reference application.
